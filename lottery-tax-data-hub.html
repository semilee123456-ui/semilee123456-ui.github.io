Methodology

Top marginal rate vs. withholding rate — these are not the same number, and this page uses both. The state table uses each state's top marginal individual income tax rate (a filing-time rate), on the assumption that a jackpot-size prize always lands in the top bracket. The country table's US-side component is a withholding rate — the IRS withholds a flat 30% from a non-resident alien's winnings at the time of payment (IRC §871(a)); this happens to also be close to the true final US federal liability for a non-resident, but it's collected as withholding, not assessed after the fact. Each country's own tax is then computed as that country's statute/treaty rate applied to the winnings, minus any Foreign Tax Credit (FTC) the country allows for the US tax already withheld — capped at the smaller of the two amounts.

Sources — every number on this page comes from ChamTax's live calculation engine (script.js's STATE_TAX_RATES and TAX_MODEL objects, and the calcTakeHome() function that applies them), the same code that powers the interactive calculator. It is not a separate spreadsheet that can drift out of sync. Full citations (statute sections, treaty articles, official tax-authority guidance) for each country are published on that country's own in-depth landing page — linked from the table above isn't practical at this scale, but every country name in the "Reuse & technical assets" section below routes to its detail page via the main site's country selector.

Confidence tiers — verified means a primary source (statute text, tax treaty article, or official tax-authority guidance) was found and directly cited; approximate means the treatment is confirmed but the exact rate is simplified (e.g. top-bracket approximation instead of full progressive-bracket math); unverified estimate means no authoritative primary source was found and the figure is a best-effort estimate from secondary sources — treat these as more likely to be wrong.

Last updated: 2026-08-18. State and country tax law changes over time (see e.g. Maine's 2026 "millionaire surcharge" or Denmark's 2026 "top-top tax" in the underlying data) — check the "Data as of" date above before citing an old cached copy of this page.
